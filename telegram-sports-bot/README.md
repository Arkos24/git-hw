### Telegram Sports Bot (RU)

Этот проект — каркас телеграм-бота, который собирает данные, строит вероятностные прогнозы на спортивные события и рассчитывает размер ставки по стратегиям банка. В репозитории реализован минимальный прототип с заглушкой источника данных (без внешних API) и базовыми моделями (Elo/Поассон) для демонстрации.

Важно: реальная эффективная система требует интеграций с платными/бесплатными провайдерами данных, нормализации лиг/команд, учёта травм и форм, и тщательной валидации моделей. Этот каркас позволит постепенно добавлять такие возможности.

### Что уже есть
- **Бот**: `aiogram 3` с командами `/start`, `/help`, `/predict`.
- **Хранилище**: SQLite (SQLAlchemy 2). Модели: `teams`, `players`, `matches`, `injury_reports`, `odds`, `predictions`, `bankroll_state`.
- **Модели**: Elo (приблизительные вероятности исходов), Поассон (распределение счёта).
- **Банкролл**: Flat/Kelly/Half-Kelly.
- **Источник данных**: `StubDataSource` — заглушка без ключей.

### Требования
- **Python**: 3.10–3.12
- **Telegram**: токен бота от `@BotFather`

### Быстрый старт
1. Перейдите в каталог проекта:
```
cd /workspace/telegram-sports-bot
```
2. Создайте `.env` из примера и укажите токен:
```
cp .env.example .env
```
Откройте `.env` и заполните `TELEGRAM_BOT_TOKEN`.

3. Установите Poetry (если не установлен):
```
curl -sSL https://install.python-poetry.org | python3 -
export PATH="$HOME/.local/bin:$PATH"
```

4. Установите зависимости и запустите бота:
```
poetry install --no-interaction
poetry run python -m bot.main
```

В Telegram напишите вашему боту `/start`, затем `/predict`.

### Конфигурация `.env`
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
DATABASE_URL=sqlite+pysqlite:///data/bot.sqlite3
ADMIN_USER_IDS=12345678,987654321
```
- **DATABASE_URL**: можно заменить, например, на PostgreSQL: `postgresql+psycopg://user:pass@host:5432/db`.
- **ADMIN_USER_IDS**: список Telegram user id через запятую (для будущих админ-команд).

### Расширение: реальные источники данных
1. Реализуйте класс в `bot/data_sources/` на основе интерфейса `DataSource` (см. `base.py`).
2. Реализуйте `fetch_upcoming_matches` и `fetch_team_info` с использованием API (`httpx`).
3. Подключите ваш источник в `bot/main.py` вместо `StubDataSource`.
4. Добавьте нормализацию лиг/команд и привязку к моделям БД.

Сигналы, влияющие на исход:
- **Форма и история**: последние N матчей, H2H, плотность календаря.
- **Кадровые факторы**: травмы, дисквалификации, стартовые составы, тренерские изменения.
- **Рынок**: движение коэффициентов, расхождение с «справедливой» ценой.
- **Контекст**: погода, покрытие, мотивация, стиль.
- **Аномалии**: резкие движения линии без новостей, подозрительная активность — потенциальные договорные матчи (используйте только законные источники).

### Про «стабильный плюс»
- **Нет гарантии ежедневной прибыли**. Просадки неизбежны даже при положительном ожидании.
- **Банкролл**: используйте Kelly/долю Kelly для контроля риска; не ставьте деньги, которые нельзя потерять.
- **Юридические риски**: соблюдайте законы и правила провайдеров данных/букмекеров.

### Текущее состояние команд бота
- `/start` — приветствие
- `/help` — помощь
- `/predict` — демо прогноз из заглушки + размер ставки Half-Kelly
